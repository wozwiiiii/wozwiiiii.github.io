APPROACH

三个项目其实在说同一件事

不是"用了 AI"，而是都在补一块容易被跳过的工作：让 demo 变成能交付的东西。

01

默认不信任SAFETY

在 deepsearch 里修掉 14 类问题——路径穿越、SQL 任意执行、横向越权、无认证、租户串台、无限流。做法是 fail-closed：没配密钥时默认拒绝服务，而不是默认放行。

02

敢改代码的底气TESTS

96 + 129 + 64 项测试，全部不依赖真实 LLM 和数据库，本地几秒跑完。不是为了覆盖率好看，是为了改代码时敢改。

03

边界写清楚HONESTY

deepsearch 明确定位为"基于开源教学项目的生产化改造"而非自研；应急 RAG 的 .wps 解析不了、限流状态在内存里，都写在 README 里。
